# XUWBK AI采集 - 主题集成方案

## 📋 方案说明

当前主题已将AI采集功能从"插件形式"转换为"主题内置功能"。

### 数据存储统一

| 功能 | 旧方案（插件） | 新方案（主题） |
|------|--------------|--------------|
| 配置存储 | `xuwbk_ai_caiji_options` | `XuWbk` 主题选项 |
| 站点配置 | `sites` 字段 | `ai_caiji_sites` 字段 |
| 数据迁移 | - | 首次访问时自动迁移 |

## 🗑️ 插件移除步骤

### 步骤1：备份数据
在移除插件前，确保配置已自动迁移到主题选项：

1. 访问主题设置 → AI采集
2. 确认网站列表中有数据
3. 如无数据，手动导出 `xuwbk_ai_caiji_options` 选项

### 步骤2：停用插件
WordPress后台 → 已安装插件 → 停用「XUWBK AI采集」

### 步骤3：删除插件
- 删除插件目录：`wp-content/plugins/xuwbk-ai-caiji/`
- 或直接在插件页面删除

### 步骤4：验证
1. 访问主题设置 → AI采集
2. 点击"手动采集"测试
3. 确认数据正常

## 🔧 常见问题

### Q1: 移除插件后采集失败？
**原因**：数据未迁移。  
**解决**：重新在主题设置中配置网站

### Q2: 付费下载模式未生效？
**解决**：已在代码中修复，现在正确读取主题选项中的配置

### Q3: 想恢复旧插件数据？
**方法**：重新配置或从备份恢复 `xuwbk_ai_caiji_options`
